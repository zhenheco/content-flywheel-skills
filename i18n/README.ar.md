# Content Flywheel — مهارات محتوى SEO و GEO

**منهجية إنتاج محتوى مفتوحة لوكلاء الذكاء الاصطناعي.** ابحث في موضوعٍ ما، وخطّط له باستخدام أقوى نموذج استدلال، ثمّ اكتب مسودّته، وأزِل عنه طابع الذكاء الاصطناعي، وشغّل بوّابة جودة GEO/SEO، ووزّعه على منصّات التواصل الاجتماعي، وانشره، وأعِد تغذية التحليلات إلى الدورة التالية — كمهارةٍ قابلة لإعادة الاستخدام في Claude Code وCursor وCodex CLI وGemini CLI وأيّ وكيل يُحمِّل مهارات Markdown.

> مبنيٌّ من أجل **Generative Engine Optimization (GEO)** — محتوى تستشهد به فعليًّا محرّكات البحث المدعومة بالذكاء الاصطناعي (ChatGPT وPerplexity وGoogle AI Overviews) — فوق مبادئ SEO الكلاسيكية.

## دولاب الموازنة

```
  ┌─────────────────────────────────────────────────────────┐
  │                                                         ↓
Research → Plan → Draft → De-AI → GEO/SEO Quality Gate → Publish → Feedback
  ↑                                                                   │
  └───────────────────  analytics tune the next cycle  ───────────────┘
```

| المرحلة | ما الذي يحدث | الدور الأمثل للوكيل |
|-------|--------------|---------------------|
| **1. البحث** | الاتجاهات، ونيّة صفحات نتائج البحث، وثغرات المنافسين، واحتياجات الجمهور | نموذج بحث/تأسيس |
| **2a. التخطيط** | المخطّط التفصيلي (H2/H3)، والأطروحة، وخطّة الروابط الداخلية، ونداء الإجراء، وخطّة البيانات المنظّمة | **أقوى نموذج استدلال** |
| **2b. كتابة المسودّة** | نصٌّ كاملٌ مكتوبٌ وفق الخطّة | نموذج كتابة سريع |
| **2c. إزالة طابع الذكاء الاصطناعي** | إزالة الحشو والصياغة العامّة و«مؤشّرات الذكاء الاصطناعي» | نموذج تحرير سريع |
| **2d. بوّابة الجودة** | تقييم المسودّة وفق قواعد **CORE-EEAT** و**GEO**؛ وسرد الثغرات | نموذج مراجعة |
| **3–4. التوزيع** | التقسيم إلى نسخٍ خاصّة بالمنصّات (FB/IG/Threads/X/LinkedIn) + شرائح متتابعة | نموذج تخطيط/كتابة |
| **5. SEO التقني** | المخطّط/JSON-LD، وCore Web Vitals (INP/LCP/CLS) | نموذج تقني |
| **6. النشر** | نشر المقالة + جدولة محتوى التواصل الاجتماعي | الأتمتة |
| **7. التغذية الراجعة** | التحليلات → ضبط أوزان أعمدة المحتوى + الوتيرة | نموذج الاستدلال |

تُحدّد **درجة الثقة** مدى استقلالية كلّ تشغيلة — من «التوقّف للمراجعة البشرية في كلّ خطوة» وصولًا إلى «أتمتة كاملة» — وترتفع أو تنخفض بحسب مقدار ما تُحرِّره من المُخرَجات.

## أُطُر GEO/SEO

تأتي جودة المُخرَجات من الأُطُر لا من الانطباعات. انظر [`frameworks/`](../frameworks/):

- **[تقنيات GEO](../frameworks/geo-techniques.md)** — تحسين التعريفات (المصطلح أوّلًا، 25–50 كلمة، قابلة للاستشهاد بها كإجابةٍ مستقلّة)، والعبارات القابلة للاقتباس (إحصاءات/حقائق/مقارنات)، وإشارات الموثوقية، وبنية الأسئلة والأجوبة، والكثافة المعلوماتية كي تقتبسك المحرّكات التوليدية.
- **[قائمة مراجعة الكتابة لـ SEO](../frameworks/seo-writing-checklist.md)** — وضع الكلمات المفتاحية، ومطابقة نيّة البحث، وسهولة القراءة، والربط الداخلي/الخارجي، واستهداف المقتطفات المميّزة.
- **[أبعاد CORE-EEAT](../frameworks/core-eeat-dimensions.md)** — بوّابة نشر قائمة على الخبرة العملية / الخبرة المتخصّصة / الموثوقية / الجدارة بالثقة (E-E-A-T) (إضافةً إلى الشمولية والأصالة وسهولة القراءة والأدلّة).

## التثبيت (كمهارة وكيل)

```bash
# Claude Code (plugin marketplace)
/plugin marketplace add zhenheco/content-flywheel-skills

# skills.sh / generic Agent Skills hosts
npx skills add zhenheco/content-flywheel-skills
```

أو ببساطة انسخ `SKILL.md` + `frameworks/` + `schemas/` إلى مجلّد مهارات وكيلك. كلّ ملفٍّ هو Markdown/YAML خالٍ من الاعتماديات — دون أيّ ارتباطٍ قسري.

1. انسخ `schemas/brand.example.yaml` ← `brand.yaml`، واملأ صوت علامتك التجارية، وجمهورك، والمؤلّفين (من أجل E-E-A-T)، وبنية عناوين URL.
2. وجِّه وكيلك إلى `SKILL.md` وشغّل دولاب الموازنة لموضوعٍ ما.
3. تُحقَن الأُطُر في خطوتَي التخطيط وكتابة المسودّة تلقائيًّا.
