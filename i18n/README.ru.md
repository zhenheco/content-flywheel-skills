# Content Flywheel — навыки для SEO- и GEO-контента

**Открытая методология производства контента для ИИ-агентов.** Исследуйте тему, спланируйте её с помощью самой сильной рассуждающей модели, напишите черновик, уберите из него «налёт ИИ», прогоните через проверку качества GEO/SEO, разнесите по соцсетям, опубликуйте и верните аналитику в следующий цикл — и всё это как многоразовый навык для Claude Code, Cursor, Codex CLI, Gemini CLI и любого агента, который загружает навыки в формате Markdown.

> Создано для **Generative Engine Optimization (GEO)** — контента, который ИИ-поисковики (ChatGPT, Perplexity, Google AI Overviews) действительно цитируют, — поверх классического SEO.

## Маховик

```
  ┌─────────────────────────────────────────────────────────┐
  │                                                         ↓
Research → Plan → Draft → De-AI → GEO/SEO Quality Gate → Publish → Feedback
  ↑                                                                   │
  └───────────────────  analytics tune the next cycle  ───────────────┘
```

| Этап | Что происходит | Подходящая роль агента |
|-------|--------------|---------------------|
| **1. Исследование** | Тренды, интент в поисковой выдаче, пробелы у конкурентов, потребности аудитории | модель для исследования и grounding |
| **2a. План** | Структура (H2/H3), тезис, план внутренних ссылок, CTA, план структурированных данных | **самая сильная рассуждающая модель** |
| **2b. Черновик** | Полный текст, написанный по плану | быстрая модель для черновиков |
| **2c. De-AI** | Убрать «воду», шаблонные формулировки, «признаки ИИ» | быстрая модель для редактуры |
| **2d. Проверка качества** | Оценить черновик по правилам **CORE-EEAT** + **GEO**; перечислить пробелы | модель для рецензирования |
| **3–4. Разнос** | Разбить на тексты под платформы (FB/IG/Threads/X/LinkedIn) + карусели | модель для вёрстки и текстов |
| **5. Технический SEO** | Schema/JSON-LD, Core Web Vitals (INP/LCP/CLS) | техническая модель |
| **6. Публикация** | Опубликовать статью + запланировать посты | автоматизация |
| **7. Обратная связь** | Аналитика → подстройка весов контент-столпов + частоты публикаций | рассуждающая модель |

**Оценка доверия** определяет, насколько автономным будет каждый запуск — от «останавливаться для проверки человеком на каждом шаге» до «полностью автоматически» — и растёт или падает в зависимости от того, насколько сильно вы правите вывод.

## Фреймворки GEO/SEO

Качество вывода рождается из фреймворков, а не из интуиции. См. [`frameworks/`](frameworks/):

- **[Техники GEO](frameworks/geo-techniques.md)** — оптимизация определений (термин в начале, 25–50 слов, цитируемых как самостоятельный ответ), цитируемые утверждения (статистика/факты/сравнения), сигналы авторитетности, структура «вопрос-ответ» и фактологическая плотность, чтобы генеративные движки цитировали вас.
- **[Чек-лист SEO-копирайтинга](frameworks/seo-writing-checklist.md)** — размещение ключевых слов, соответствие поисковому интенту, читабельность, внутренние/внешние ссылки и нацеливание на featured-сниппеты.
- **[Измерения CORE-EEAT](frameworks/core-eeat-dimensions.md)** — публикационный шлюз по осям Experience / Expertise / Authoritativeness / Trustworthiness (плюс полнота, оригинальность, читабельность, доказательность).

## Установка (как навык агента)

```bash
# Claude Code (plugin marketplace)
/plugin marketplace add zhenheco/content-flywheel-skills

# skills.sh / generic Agent Skills hosts
npx skills add zhenheco/content-flywheel-skills
```

Или просто скопируйте `SKILL.md` + `frameworks/` + `schemas/` в каталог навыков вашего агента. Каждый файл — это Markdown/YAML без зависимостей, без привязки к платформе.

1. Скопируйте `schemas/brand.example.yaml` → `brand.yaml`, заполните голос бренда, аудиторию, авторов (для E-E-A-T) и структуру URL.
2. Направьте агента на `SKILL.md` и запустите маховик для какой-нибудь темы.
3. Фреймворки автоматически внедряются в шаги планирования и написания черновика.
